## Topic 1: Closures

A **closure** is a function that remembers variables from its outer scope even after the outer function has finished executing.

```js
function makeCounter() {
  let count = 0;
  return function () {
    count++;
    return count;
  };
}

const counter = makeCounter();
console.log(counter()); // 1
console.log(counter()); // 2
console.log(counter()); // 3
```

**Key Points:**
- Inner function retains access to outer variables after parent returns.
- Each call to `makeCounter()` creates a new independent closure.
- Used for data encapsulation, factory functions, and event handlers.

## Topic 2: Promises

A **Promise** represents the eventual result of an async operation — either `fulfilled` or `rejected`.

```js
const fetchData = new Promise((resolve, reject) => {
  setTimeout(() => resolve("Data fetched!"), 1000);
});

fetchData
  .then((result) => console.log(result))
  .catch((error) => console.error(error));
```

**Chaining:**
```js
fetch("https://api.example.com/user")
  .then((res) => res.json())
  .then((data) => console.log(data.name))
  .catch((err) => console.error(err));
```

**Key Points:**
- `.then()` for success, `.catch()` for errors.
- Avoids callback hell with clean chaining.
- `Promise.all([p1, p2])` runs promises in parallel.

## Topic 3: Event Delegation

**Event Delegation** attaches one listener to a parent element to handle events from all its children.

```js
// Without delegation (inefficient)
document.querySelectorAll("li").forEach((li) => {
  li.addEventListener("click", (e) => console.log(e.target.textContent));
});

// With delegation (efficient)
document.querySelector("ul").addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    console.log("Clicked:", e.target.textContent);
  }
});
```

**Key Points:**
- Events bubble up from child to parent — the parent catches them.
- Works for dynamically added elements automatically.
- Improves performance for large lists.
